# Lumo's Light-Up Lab: the code

These are the 14 programs (sketches) from the book **Lumo's Light-Up Lab: 14 Blink, Beep & Move Projects for Kids 9-12** by Rose M. Gold.

Typing the code yourself is great practice! Use these files if you get stuck, or to check your typing.

## How to download

1. Click the green **Code** button near the top of this page.
2. Click **Download ZIP**.
3. Unzip the file. Each project is in its own folder.
4. In the Arduino IDE, choose **File > Open** and open the `.ino` file inside a project's folder.

## Safety

These projects run only on the 5 V power from a computer's USB port. Build them with an adult nearby, and never connect a project to a wall socket.
