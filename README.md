# Lumo's Light-Up Lab – the code

All 14 programs from *Lumo's Light-Up Lab* by Rose M. Gold are in the
**[lumolab_code_repo](lumolab_code_repo/)** folder, one folder per project.

**To download:** click the green **Code** button above → **Download ZIP**, unzip it,
then open a project's `.ino` file in the Arduino IDE (File → Open).

Typing the code yourself is great practice – use these files to check your work!
Projects run on USB power only. Build with an adult nearby.
